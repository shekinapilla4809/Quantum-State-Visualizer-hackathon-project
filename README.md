# ⚛️ Quantum Circuit → Bloch Visualizer

### AQVH – Quantum Computing Hackathon Project

A web-based **Quantum State Visualizer** that helps users understand quantum computing by converting quantum circuits into interactive **Bloch Sphere visualizations**.

The project allows users to create or analyze quantum circuits, apply different quantum gates, simulate quantum states, and visualize the state of individual qubits.

---

## 🚀 Project Overview

Quantum computing concepts can be difficult to understand because quantum states are not directly visible.

**Quantum Circuit → Bloch Visualizer** provides a visual way to understand how quantum gates affect quantum states.

The application takes a quantum circuit as input and:

**Quantum Circuit → Quantum Simulation → Quantum State → Bloch Sphere Visualization**

This makes quantum concepts easier to explore and understand.

## 🧠 How It Works

### 1. Create a Quantum Circuit

The user creates a quantum circuit using supported quantum gates.

### 2. Simulate the Circuit

The circuit is processed using **Qiskit** to calculate the resulting quantum state.

### 3. Calculate the Quantum State

The application obtains the quantum statevector generated by the circuit.

### 4. Analyze Individual Qubits

For multi-qubit systems, the application analyzes individual qubit states.

### 5. Visualize on Bloch Sphere

The resulting single-qubit states are represented visually using Bloch spheres.

This allows users to see how quantum gates transform quantum states.

## 📂 QASM Support

The application supports uploading quantum circuits using **OpenQASM** files.

Users can upload a QASM circuit and visualize the resulting quantum state.

Example workflow:

```text
QASM File
   ↓
Quantum Circuit
   ↓
Qiskit Simulation
   ↓
Quantum State
   ↓
Bloch Sphere
```

## 📊 Example

Consider a single qubit initially in:

```text
|0⟩
```

Applying a Hadamard gate:

```text
H|0⟩
```

creates a superposition:

```text
(|0⟩ + |1⟩) / √2
```

The Bloch Sphere visualization represents this quantum state geometrically.

## 🎯 Problem Statement

Quantum computing education often relies heavily on mathematical notation and abstract concepts.

Students and beginners may find it difficult to understand how quantum gates change quantum states.

This project addresses the problem by providing a visual and interactive environment for exploring quantum states.

---

## 💡 Proposed Solution

The **Quantum Circuit → Bloch Visualizer** bridges the gap between quantum circuit operations and their visual representation.

Instead of only displaying numerical quantum states, the application provides an intuitive visual representation through Bloch spheres.

This helps users:

* Understand quantum gates
* Observe state transformations
* Explore superposition
* Understand quantum state changes
* Experiment with multi-qubit circuits
